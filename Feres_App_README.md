# Feres App

Feres is a modern ride-hailing mobile application that connects
passengers with nearby drivers quickly, safely, and efficiently. The app
allows users to book rides, receive real-time updates, and manage their
trips easily.


##  Features

### Ride Booking

-   Book a ride instantly
-   Real-time driver tracking
-   Estimated fare calculation
-   Trip history management

###  Promotions

-   Apply promo codes
-   Receive special ride discounts
-   View active offers

### Referral System

-   Invite friends using referral code
-   Earn rewards for successful referrals
-   Track referral earnings

### Notifications

-   Ride status updates
-   Driver arrival alerts
-   Promotional notifications

### Support

-   In-app customer support
-   Help center and FAQs
-   Contact support team
